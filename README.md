# Packing List → форма загрузки ВЭД (1С)

Скрипт `pl_to_ved.py` берёт упаковочный лист (Packing List, `.xlsx`) и создаёт
отдельный Excel-файл с колонками для «Формы загрузки ВЭД»:

| Контейнер | Номер пломбы | Вес | Количество | Страна |
|-----------|--------------|-----|------------|--------|
| CICU7418771 | XHL200914 | 15749 | 214 | Вьетнам |

Одна строка на контейнер, пустых строк нет. Данные со второй строки можно
скопировать целиком и вставить в форму 1С.

## Что делает

- находит таблицу по заголовкам `Container No./Seal No.`, `Quantity`, `G.W/N.W`;
- делит `CICU7418771/XHL200914` на номер контейнера и номер пломбы;
- суммирует количество и вес по всем товарным строкам контейнера;
- сверяет суммы со строками `SUBTOTAL` и `TOTAL` и пишет предупреждение при расхождении;
- проверяет контрольную цифру номера контейнера (ISO 6346);
- определяет страну по строке `COUNTRY OF ORIGIN` (если её нет — по `MANUFACTURER`
  или `PORT OF LOADING`) и пишет её по-русски, например «Вьетнам».

## Установка

```
pip install -r requirements.txt
```

## Запуск

```
python pl_to_ved.py PSS-VN-2607-7_PL.xlsx
```

Результат сохраняется рядом с исходником: `PSS-VN-2607-7_PL_ВЭД.xlsx`.

Другие варианты:

```
python pl_to_ved.py PL1.xlsx PL2.xlsx              # несколько файлов сразу
python pl_to_ved.py PL.xlsx -o результат.xlsx      # своё имя файла результата
python pl_to_ved.py PL.xlsx --country Вьетнам      # страна вручную
python pl_to_ved.py                                # окно выбора файлов
```

В Windows можно просто перетащить файл(ы) на `pl_to_ved.bat`.
